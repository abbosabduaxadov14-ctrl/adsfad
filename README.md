## Frontend source

Open the root `index.html` in a browser to use the single-file edition. It bundles the HTML, JavaScript, CSS, course data, images, and fonts. For hosted sign-in, serve the file over HTTP and configure the Supabase callback for `index.html?page=signin`. YouTube playback requires an internet connection and a supported HTTP origin.

Run `node tools/build-single-file.cjs` after changing the frontend source to regenerate `index.html`.

- `frontend/landing` and `frontend/catalog` contain the homepage, catalog and course data.
- `frontend/auth`, `frontend/watch` and `frontend/notes` contain sign-in, the course player and saved notes.
- `frontend/lesson`, `frontend/discovery` and `frontend/team` contain the lesson, interest quiz and team route.
- `frontend/shared`, `frontend/assets` and `frontend/vendor` contain shared styles, images and fonts, and the bundled Supabase client.

`web-config.cjs` maps the public URLs to these packages. The local server and `node prepare-release.cjs --preview` use that mapping so links such as `/watch.html?course=mit-micro` work in both environments. `frontend/` is the only active source; old duplicate copies were removed.
